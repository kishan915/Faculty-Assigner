Workload Merge Console

Upload the three source workbooks — coordinators, subject faculty, and workload — plus an optional M.Tech scheme file. Subject codes are normalized (the common I↔1 mix-up), auto-corrected when a typo is within one character of exactly one official code, and Subject Name is replaced with the official UPPERCASE name wherever a code is confidently verified. Unresolvable codes are highlighted red; auto-corrected ones yellow. You get back one flat final_input.xlsx — no grouping.
